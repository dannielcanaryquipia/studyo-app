# Grafema — Ang Alpabeto na Sorsoganon

Ang **grafema** ay isang bahagi o pangkat ng mga bahagi sa sistema ng pagsulat. Maaari itong maging isang titik, kombinasyon ng mga titik, o di-titik.

## 1.1 Titik (Letra)

Ang mga titik ay simbolo ng bawat tunog sa pagsasalita. Ang **alpabetong Sorsoganon** ay binubuo ng **dalawampu't walong (28) titik**. Ito ay may limang (5) patinig at dalawampu't tatlong (23) katinig. **Walo (8)** sa mga ito ay hiram na titik: ⟨c, f, j, ñ, q, v, x, z⟩.

| Titik | Pangalan | Titik | Pangalan |
|---|---|---|---|
| Aa | ey | Bb | bi |
| Cc | si | Dd | di |
| Ee | i | Ff | ef |
| Gg | ji | Hh | eyts |
| Ii | ay | Jj | jey |
| Kk | key | Ll | el |
| Mm | em | Nn | en |
| Ññ | enye | NGng | enji |
| Oo | o | Pp | pi |
| Qq | kyu | Rr | ar |
| Ss | es | Tt | ti |
| Uu | yu | Vv | vi |
| Ww | dobolyu | Xx | eks |
| Yy | way | Zz | zi |

> Ang **NG** ay isang digrapo — isang tunog lamang ngunit dalawang titik ang kumakatawan dito. Kinakatawan nito ang ponemang /ŋ/.

## 1.2 Di-Titik

Ang mga di-titik ay binubuo ng mga **tuldik** at **bantas**. Ang tuldik ay mga simbolong inilalagay sa itaas ng titik para katawanin ang ilang tunog o pamamaraan ng pagbigkas.

| Tuldik | Simbolo | Gamit |
|---|---|---|
| Pahilis | ´ | Sumasimbolo sa **diin at haba**. Inilalagay sa itaas ng patinig. |
| Paiwa | ` | Ginagamit upang katawanin ang **impit na tunog** (glottal stop) sa pantig na walang diin. |

**Halimbawa ng pahilis:**
- *sálog* /ˈsa.luɡ/ — ílog
- *salóg* /sa.ˈluɡ/ — sahíg

**Halimbawa ng paiwa:**
- *páhâ* /ˈpa.haʔ/ — uhaw
- *higdá* /ˈhig.daʔ/ — higâ

Ginagamit din ang **gitling** bilang simbolo ng impit na tunog na may kasunod na patinig sa gitna ng salita:
- *bág-ot* /ˈbaɡ.ʔot/ — pawis
- *tám-is* /ˈtam.ʔis/ — tamís

Katulad sa Filipino ang paggamit ng mga sumusunod na bantas sa Sorsoganon:

| Bantas | Tawag |
|---|---|
| . | Tuldok |
| ? | Tandang Pananong |
| ! | Tandang Padamdam |
| , | Kuwit |
| ; | Tuldok-kuwit |
| : | Tutuldok |
| ' | Kudlit |
| - | Gitling |
| " " | Panipi |
| ( ) | Panaklong |

## 1.3 Ang Diin ay Ponemic

Ang diin sa pantig ay may kaugnayan sa kahulugan ng salita sa Sorsoganon. Nagbabago ang kahulugan ng magkaparehong salita kapag inililipat ang diin sa ibang pantig:

| Unang Pantig | | Ikalawang Pantig | |
|---|---|---|---|
| sálog | ílog | salóg | sahíg |
| úlì | uwî | ulî | suklî |
| túkal | palít | tukál | tanggál |
| bákal | bákal | bakál | bilí |
| túrog | tulog (pangngalan) | turóg | tulog (pang-uri) |
