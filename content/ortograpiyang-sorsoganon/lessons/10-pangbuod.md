# Pangbuod — Mga Pangunahing Tuntunin

Narito ang isang buod ng lahat ng mahahalagang tuntunin ng Ortograpiyang Sorsoganon.

## Alpabeto

Ang alpabetong Sorsoganon ay binubuo ng **28 titik** — 5 patinig, 23 katinig (kasama ang 8 hiram na titik). Ang NG ay isang digrapo na kumakatawan sa ponemang /ŋ/.

## Diin

Ang diin sa pantig ay **ponemiko** sa Sorsoganon — nagbabago ang kahulugan ng salita kapag inilipat ang diin:
- *sálog* (ílog) ≠ *salóg* (sahíg)
- *túkal* (palít) ≠ *tukál* (tanggál)

## Pagbabaybay ng mga Katutubong Salita

Sundin ang tuntunin na **"Kung ano ang hilwas, mao ang surat"** para sa mga katutubong salita ng Sorsoganon.

## Mga Pangunahing Tuntunin

| Tuntunin | Halimbawa |
|---|---|
| NG para sa /ŋ/ | *ngaran*, hindi *gñaran* |
| "Mga" para sa pangmaramihan | *mga balay*, hindi *mga balays* |
| H sa -on/-an kung walang katinig | *matahon* (mata + -on) |
| Pang- → pam- bago p, b | *pambalay* (pambahay) |
| Pang- → pan- bago d, s, l, r, t | *pansurat* (pansulat) |
| Pang- + gitling bago patinig | *pang-abay* |
| L/R alternation | *ralaba* (laba), *ruluto* (luto) |

## Mga Salitang Hiram

| Tuntunin | Halimbawa |
|---|---|
| Mahina i → y bago patinig | *kompanya*, *benepisyo* |
| Mahina u → w bago patinig | *manwal*, *awto* |
| CH: 3 pagpipilian | *tsek / check / kemikal* |
| SH: panatilihin | *shampoo* |
| S + katinig: orihinal o i- | *iskor / score* |
| Español g/j + /h/ → h | *kolehiyo*, *huwes* |
| Double consonants → single | *komite* (committee) |
| Silent h sa Español → tanggalin | *arina* (harina) |

## Palitang Patinig

| Tuntunin | Halimbawa |
|---|---|
| Katutubong salita → laging i | *diri*, *ini*, *pira* |
| Español na es- → e | *eskuwela* |
| Ingles na s- → i | *iskul* |
| Gitna ng Español → i, hindi e | *disgrasya*, hindi *desgrasya* |
| Español na nagsisimula sa o- → o | *opisina*, hindi *upisina* |
| Huling silaba → o | *sayô*, *tukdô* |
| Ibang posisyon → u | *sugpon*, *tulo* |

## Mga Pagkakaiba mula sa Filipino

Mahalaga ang mga sumusunod na pagkakaibang ito:

1. **NG:** Kapwa ginagamit ng Filipino at Sorsoganon, ngunit ang Sorsoganon ay nagsisimula sa NG ang maraming salita (*ngaran*, *ngipon*).
2. **Diin:** Mas prominente ang papel ng diin sa pagbabago ng kahulugan sa Sorsoganon.
3. **L at R:** May natatanging palitang L/R sa pamamagitan ng panlaping {-Pr-} at {Kuru-} — hindi ito mayroon sa Filipino.
4. **Pagbabaybay ng o/u:** Ang Sorsoganon ay may mas malinaw na distribusyon ng ⟨o⟩ (huling silaba) at ⟨u⟩ (ibang posisyon).
5. **Wikang Bisakol:** Dahil sa Bisaya at Bikol na pinagmulan, ang maraming salita sa Sorsoganon ay hindi makikita sa Filipino.

> Ang Ortograpiyang Sorsoganon ay isang buháy na dokumento — patuloy na nagbabago habang ang wika ay lumalago at umuunlad.
