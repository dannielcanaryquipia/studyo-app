# Pahilwas na Pag-ispeling (Pagbaybay na Pasalita)

Isa-isang binibigkas sa maayos na pagkakasunod-sunod ang mga titik na bumubuo sa isang **pantig, salita, akronim, daglat, inisyals, simbolong pang-agham,** atbp.

## 3.1 Pantig

| Pagsulat | Pagbigkas |
|---|---|
| an | ey-en |
| kun | key-yu-en |
| man | em-ey-en |
| sin | es-ay-en |
| san | es-ey-en |

## 3.2 Salita

| Pagsulat | Pagbigkas |
|---|---|
| ingkod *(upô)* | ay-enji-key-o-di |
| hatag *(bigay)* | eyts-ey-ti-ey-ji |
| imbuwelto | ay-em-bi-yu-dobolyu-i-el-ti-o |
| Forteza | kapital ef-o-ar-ti-i-zi-ey |

## 3.3 Akronim

Isa-isang binibigkas ang bawat titik na may salitang "kapital" para sa malalaking titik:

| Pagsulat | Pagbigkas |
|---|---|
| TESDA | kapital ti-kapital i-kapital es-kapital di-kapital ey |
| DepEd | kapital di-i-pi-kapital i-di |
| PAGASA | kapital pi-kapital ey-kapital ji-kapital ey-kapital es-kapital ey |
| SORECO | kapital es-kapital o-kapital ar-kapital i-kapital si-kapital o |
| COMELEC | kapital si-kapital o-kapital em-kapital i-kapital el-kapital i-kapital si |

## 3.4 Daglat

| Pagsulat | Pagbigkas |
|---|---|
| Kap *(Kapitan)* | kapital key-ey-pi |
| Kgwd. *(Kagawad)* | kapital key-ji-dobolyu-di tuldok |
| Sta. *(Santa)* | kapital es-ti-ey tuldok |
| Brgy. *(Barangay)* | kapital bi-ar-ji-way tuldok |
| Sr. *(Senior)* | kapital es-ar tuldok |

## 3.6 Simbolong Pang-agham at Pangmatematika

| Pagsulat | Pagbigkas |
|---|---|
| H₂O | kapital eyts-tu-kapital o |
| Ag *(silver)* | kapital ey-ji |
| Na *(salt)* | kapital en-ey |
| cm. | si-em tuldok |
| kg. | key-ji tuldok |

> **Tandaan:** Sa pagbabaybay ng salita sa Sorsoganon, ginagamit ang mga pangalan ng titik ayon sa alpabetong Sorsoganon (halimbawa: ang *g* ay "ji", ang *h* ay "eyts", ang *y* ay "way").
